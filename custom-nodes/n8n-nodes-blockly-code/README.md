# Blockly Logic

`Blockly Logic` is an n8n transform node for deterministic per-item logic that
would otherwise require local JavaScript in a Code node. Blockly is embedded in
the node parameter panel: n8n still owns workflow orchestration, while the
workspace expresses the node's data details visually.

The installed node type is `n8n-nodes-blockly-code.blocklyCode`, type version `1`, and its
single parameter is `blocklyPayload`.

## Runtime contract

- The node runs once per incoming item and returns exactly one JSON item for it.
- The workspace is the only execution source of truth. Saved preview JavaScript
  is ignored and regenerated by the shared compiler before every execution.
- Supported logic includes field reads and writes, delete, conditional
  statements, assertions, arrays, object construction, type conversion, text,
  arithmetic, comparisons, booleans, and conditional values.
- Array projection and filtering are bounded to an existing input array. General
  loops and variables are outside the grammar.
- Execution uses n8n's JavaScript task runner in chunks of 1,000 items.
- The output is JSON only. There is no binary editing, external I/O, credentials,
  async action, npm module access, or arbitrary JavaScript escape hatch.
- Payload schema version 2 is required.

## Development

Build the shared compiler first from the repository root, then run the node
checks:

```bash
pnpm --filter @n8n/blockly-data-transform build
cd custom-nodes/n8n-nodes-blockly-code
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm pack --pack-destination ../../../node_modules/.cache/blockly-logic-pack
```

`@n8n/blockly-data-transform` is bundled into the compiled node. The published
custom-node artifact therefore has no runtime dependency other than the
host-provided `n8n-workflow` peer.
